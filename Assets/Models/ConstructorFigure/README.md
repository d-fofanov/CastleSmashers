# ConstructorFigure

One static mesh object, 1188 triangles, explicit normals. No colors, materials, textures or rig. Assign your material in Unity.

Dimensions X/Y/Z: 0.354000 / 0.480000 / 0.120000 metres. Y up, identity transform. Figure faces +Z, pivot at foot level. Separate closed shells are combined in one mesh; not boolean-unioned.
